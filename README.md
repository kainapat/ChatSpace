# ChatSpace

Private rooms for small-group chat with per-room video and whiteboard.

Monolith MVP: Node + Express + Socket.IO + SQLite. `npm install && npm start`.

## Status

MVP scaffolding in progress. See `CONTEXT.md` for ubiquitous language and `docs/adr/` for decisions.

## Run (after scaffold)

```bash
npm install
npm start
```

Open http://localhost:3000
